# Coffee Shift — project instructions

## Project Overview

Coffee Shift is a mobile-first browser game that teaches players to prepare and
serve coffee by fulfilling customer orders during short café shifts. The MVP
covers 5 drinks, 3 customer archetypes, 3 minigames (espresso extraction, milk
texturing, drink assembly), Learn/Practice/Shift modes and ~20 levels. All UI
copy, in-game messages and technical docs are **British English**.

## Tech Stack (actual installed versions)

- Node v22.23.2, npm 10.9.8
- Vite ^8.2.2, vanilla TypeScript (strict, `noUncheckedIndexedAccess`)
- Phaser ^4.2.1 (gameplay canvas)
- vite-plugin-pwa ^1.3.0 (installable PWA, offline precache)
- Vitest ^4.1.11 (domain unit tests, node environment)

## Naming & Coding Conventions

- Domain layer (`src/domain/**`) is **pure TypeScript** — no Phaser/DOM imports. Ever.
- UI copy files (`src/ui/copy.ts`) are the only place user-facing strings live.
- File naming: kebab-case. Exported symbols: PascalCase.
- Pixel sprites are data modules in `src/sprites/` (`{ w, h, rows }` string maps), never binary assets.
- Recipes live only in `src/domain/recipes.ts` (House Standard, single source of truth) — never in scene code.

## Protected Files

- `CHANGELOG.md` — release history; edit only via the release workflow (Keep a Changelog).
- `public/icons/*` — generated by `npm run prebuild` (`scripts/generate-icons.mjs`); regenerate, never hand-edit.

## Release workflow

SemVer from `v0.0.1`. Bump version → fold `[Unreleased]` into a version section → commit `chore(release): vX.Y.Z — …` → annotated tag → push with tag → `gh release create` with the CHANGELOG section as notes.
